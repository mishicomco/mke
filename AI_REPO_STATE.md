## Qué es

MKE (Mishi Kubernetes Engine) = la plataforma que sirve `*.mishi.com.co`. Un mismo sabor de k8s (k3d/k3s) replicado por overlays Kustomize, cambiando solo configuración, nunca código. Repo de la plataforma (clusters, componentes base in-cluster, scripts); las apps viven en sus propios repos.

- **`mke deploy` = EL pipeline completo (rama `deploy-convergente`, NO mergeada):** absorbe las ~280 líneas de YAML que cada app duplicaba en su `ci-cd.yml`; el workflow queda delgado (`templates/ci-cd.yml`) y solo llama `mke deploy <app> <env> --dir $GITHUB_WORKSPACE`. Fases fail-fast: **lint de migraciones PRIMERO** (`lintMigraciones.ts`, mudado del repo de cada app — antes solo corría en el job `quality` de PRs y el ecosistema no usa PRs, así que estrenaba en el deploy a prod) → **preflight convergente** (`preflightDeploy.ts`: ns, BD+Secret k8s en SU entorno, CNAME repunteado al túnel vivo, host del front en el ingress **VIVO** de static-mishi, no solo en el overlay git) → build backend+frontend (token npm del forge de `vault-mishi get git-mishi-npm-token`, `VITE_IDENTITY_URL` horneado por env en `mkeConfig.ts`) → `k3d image import` → `apply -k` con **re-pin** de la imagen viva → dump pre-migración (`dumpPreMigracion.ts`) → Job de migrar → **drift-check** (`driftDb.ts`) → `set image :sha` + rollout → publicar front al PVC → **catálogo** → **postflight `doctor` (sin cadena pública sana el deploy NO es verde)**. La FORMA de la app se DERIVA (`appSpec.ts`: overlay + `.mishi-app.json` + árbol), sin flags obligatorias ni registro central. `mke preview merge` corre el MISMO lint antes de mergear a main. `--dry-run`/`--sin-preflight` para depurar.

Hornea lo que costó una odisea descubrir: el forge se alcanza por LAN, el token es `git-mishi-api-token`, los ids de `/actions/tasks` NO sirven para logs (el endpoint es `/actions/runs/{id}/logs` y devuelve **ZIP**, con el `id` GLOBAL, no el `index_in_repo`), y Forgejo manda el veredicto en `status` + la rama en `prettyref` (no `conclusion`/`head_branch`). El ZIP se descomprime EN PROCESO (`zipLeer.ts`): el pc gamer no tiene `unzip`. `ci deploy` VALIDA el input `environment` (un input desconocido caía en silencio a stage con run verde).

- Subdominios: no-prod con guion (`<app>-local`, `<app>-stage`), prod pelado (`<app>`). Detalle y footguns en `AI_ARCHITECTURE.md`.
